    ℹ️ About PhishGuard

    🎣 What is Phishing?

    Phishing is a type of cyber-attack where criminals create fake websites or send deceptive messages that impersonate legitimate organisations (banks, e-commerce sites, social networks) to steal sensitive information such as passwords and credit card numbers.

    Phishing URLs often have tell-tale signs: they use IP addresses instead of domain names, contain suspicious keywords like "login", "verify" or "secure", include an unusually large number of sub-domains, or don't use HTTPS.

    🤖 How PhishGuard Works

    PhishGuard performs static analysis only — it never visits the submitted URL. It extracts 25 structural features from the URL string and feeds them to two independently trained models:

    • Random Forest – an ensemble of decision trees that votes on the classification.
    • Neural Network – a 4-layer deep learning model trained with Keras/TensorFlow.

    The final verdict is determined by a majority-vote ensemble of the two models, with confidence as the tiebreaker.

    📐 URL Features Analysed

    • URL length & entropy
    • Number of dots, hyphens, underscores, slashes
    • HTTPS presence
    • IP address in host
    • Subdomain depth
    • Domain & path length
    • Number of query parameters
    • Suspicious keywords (login, verify, paypal, …)
    • Special characters count
    • Port number presence
    • Double-slash redirect pattern

    🛠️ Technology Stack

    • Backend: Python · Flask
    • ML: Scikit-learn (Random Forest)
    • DL: TensorFlow / Keras
    • Data: Pandas · NumPy
    • Database: SQLite
    • Frontend: HTML5 · CSS3 · Vanilla JS · Chart.js
